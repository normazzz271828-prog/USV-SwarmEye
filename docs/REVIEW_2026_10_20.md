# Whole-site review — 2026-10-20

## Confirmed findings and repairs

| Area | Finding | Change |
|---|---|---|
| Quantum field | A faint composite image was presented without a distinct quantum contribution or scale | Separate quantum/composite/off layer selection, contrasting palette, current peak and numeric color scale |
| Field intensity | Per-frame normalization hid actual temporal strength changes | Fixed maximum per layer over the excerpt; raw peaks and scales are exported |
| Playback | Long requestAnimationFrame gaps could skip ahead after backgrounding | Pause on hidden document, reset timing on resume, ignore long suspended-frame deltas |
| Navigation | Leaving the console lost time, speed and layer selection | Bounded per-component cache restores paused progress for unchanged config/form revision |
| Idle performance | Paused players kept requesting animation frames | Frame loop runs only while playing; listeners and loops cleaned up on unmount |
| Route interpretation | Actual traces lacked a visible reference route | O/S/Z reference routes rendered with dashed lines |
| Archive | Closest-distance calculation considered only T1–T3 | Include every target; regression fixture places T9 closest |
| Fusion domain | Changing group membership could drop a domain for a full frame | Preserve the current sampled domain until the next group state; correct terminal sample |
| Load failure | Error message could become the root node targeted by DOM patching | Insert warning inside the site shell |

## Remaining limitations

The field is the supplied algorithm's spatial Gaussian construction; this review
adds clarity, not a new physically validated quantum solver. Layer scales are fixed
within one excerpt, not across different parameter runs. The pair risk index and
field strength remain distinct quantities. Original research models still have no
autonomous controller; O/S/Z are separate control examples.

Member avoidance can reduce external obstacle clearance, as documented in
CONTROL_MODELS.md. This review does not establish collision freedom for arbitrary
parameters or initial overlap. Reference-route display and playback fixes do not
change that limitation. Cloud cold starts and computation/network latency remain;
loading feedback and compressed transport are retained. Browser progress is
session-local and is not persisted across a full browser refresh.
