# 编队演示与加密存档更新

本次发布增加三角编队、S 形编队，共八类场景、十六组预设。新编队为九艘外部船和一艘本船，使用在本工程中独立编写的几何生成与解析运动模型；没有导入、复制或打包保密研究目录的源码、数据、视频或参数配置。

编队中心采用 24 秒连续速度过渡，编队做小幅连续摆动。每艘船的速度包含摆动的位置导数，避免位置动画与计算速度脱节。它仍是未标定的运动学演示，不代表真实操纵动力学。

融合边界加重显示并保留单船域。空间影响层使用以目标位置为中心的固定尺度柔光示意，可开关；它不代表 GPS 标准差、量子计算结果或碰撞概率，不参与既有 CPA 风险规则。图层沿用所选的仿真/观测数据源，不混用真值与观测。

片段结束后提供「补齐计算并进入复盘」，明确将剩余仿真计算到 180 秒，再开放完整复核与比较，保留此前人工处置；不再出现片段结束却无法复盘的流程断点。原有六类运动模型、方法版本及旧记录校验语义保留。

## 加密范围

「加密保存记录」在浏览器使用 Web Crypto：AES-256-GCM、随机 16 字节盐、随机 12 字节 nonce、PBKDF2-SHA256 600000 次派生、128 位认证标签及固定关联数据。用户设置至少 12 字符的密码，二次确认后导出 `.swarm` 文件。密码与派生密钥不进入服务器动作消息、会话字段、localStorage 或项目配置。HTTPS 或 localhost 是加密功能的运行条件。

恢复加密文件时在浏览器输入密码并验证认证标签，解密后将普通记录送给现有服务端恢复校验器。密码错误、内容修改或损坏均拒绝恢复。密码无法由平台找回。加密只保护导出文件；打开的浏览器仍能查看当前画面与已显示证据，普通 JSON/HTML 导出仍是明文。

GitHub 仓库为公开仓库。本更新不把公开代码混淆称作源码保密；研究原始代码继续仅存本地。本次云端仅运行本仓库独立演示代码。若后续接入保密研究内核，需要另行确定私有服务与访问控制。

## 验证

验证包括旧测试、十船轨迹/速度一致性、全时间视野、九目标风险证据、未来数据过滤、恢复重算、文件尺寸，以及真实浏览器的加密下载、错误密码拒绝、正确恢复、完整复盘和移动端。

2026-10-19 本地验证：52 项计算测试通过；桌面和移动端浏览器验收通过，包括十船连续播放、影响层切换、密码二次确认、加密下载、密码未出现在发出的 WebSocket 帧中、错误密码拒绝、正确恢复、密文修改拒绝，以及完整复盘追加意见。截图和测试存档位于忽略的 artifacts/，未提交运行记录。

代码通过 GitHub main 更新；云端功能验收独立于代码推送和 CI。Streamlit Cloud 可能在外层平台页内嵌实际应用，自动验收需进入实际应用框架或对应运行路径。浏览器脚本接受目标 URL，也支持通过环境变量 SWARMEYE_BROWSER_PROXY 指定本机代理；不在源码中保存代理凭据。
