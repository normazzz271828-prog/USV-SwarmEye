# 首版方法与验收

实现版本：`demo-0.1.0`。本版使用明确登记的工程演示假设，不使用尚未核查的论文域系数，也不宣称精确复现论文 A / B。

## 场景与参数

坐标为本地东 / 北米制，无地理配准。时长 180 s，采样 1 s，1 艘本船和 3 艘外部目标。确定性场景不使用随机误差，因此不需要随机种子。

- 本船：初位 `(0, -400)` m，速度 `(0, 4)` m/s。
- 外部船 01：初位 `(-450, 120)` m；02：`(-490,145)` m；03：`(-530,120)` m。
- 外部船初速 `(4.5,0)` m/s；90 s 转向为 `(1.5,4)` m/s。位置连续，速度方向突变为理想化演示设定。
- 观测延迟：本船 0 s，外部目标可选 0 / 20 s。两组仅到达时间不同。
- 观测时效上限 30 s；不足或过时不能输出安全结论。
- 船舶域半轴 60 / 35 m，随观测速度方向旋转；显示采样 48 点凸包。保护圆半径 60 m，显示为点线圆。
- 分群使用观测状态：距离 ≤ 120 m、航向差 ≤ 15°、速度差 ≤ 1 m/s，取连接分量。本船始终排除；成员排序形成可重复标识，不依赖真值队属。

所有数值来源都是工程演示假设；不对应设备标定、真实船长或安全标准。

## 规则

- `DQ-01`：必要观测不足或超过 30 s，请求核实，保留已有事件等级与证据。
- `RISK-01`：数据有效，任一本船—目标的中心距离 ≤ 120 m，立即 L3；采用两保护圆侵入判断，不把凸包显示当作参与计算的融合几何。
- `RISK-02`：数据有效，0 < TCPA ≤ 60 s 且 DCPA < 150 m，连续 3 帧形成 L2；低相对速度时 TCPA 为未定义，不伪造无穷值或风险。
- 解除：连续 5 个有效样本，距离 > 120 m，且预测窗口内没有 DCPA < 170 m 的目标。有效新样本显示硬约束不再成立时，L3 至少降为 L2；数据不足时保留旧等级。
- 一个持续会遇只产生一个事件，等级变化追加到事件历史。暂缓必须填写复核条件；人工判断不修改规则输出或轨迹。

事件归并为当前四船场景的一条连续会遇。尚未提供多场景、交错独立会遇的泛化关联机制；新增场景前需扩展并验证事件关联策略。

## 计算验收结果

- 延迟运行：56 s 触发 L2，100 s 升级 L3，110 s 收到转向观测降为 L2，178 s 解除。
- 即时基线：56 s 触发 L2，无 L3，178 s 解除。
- 隐藏真实轨迹全程最近船间距离为 160.0 m，未进入本版 120 m 硬约束。该对照只解释迟到观测的影响，不自动构成误报率。
- 180 s 两组均为有效观测、当前未触发演练规则。
- 演练时钟只能前进；完整真值仅在运行完成后展示。最终 20 s 内仍未到达的目标观测不回填过去的决策，事后真值独立标识。
- JSON 恢复重放相同配置并逐项校验历史、事件、参数和决策证据，拒绝不一致记录。
